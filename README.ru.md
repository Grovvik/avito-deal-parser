# Avito Deal Parser

[Read in English](README.md)

Мощная система мониторинга объявлений Avito с расширяемой архитектурой скраперов, поддержкой нескольких каналов уведомлений и современным веб-интерфейсом на React. Использует Playwright для парсинга как JSON-состояния, так и HTML результатов поиска, фильтруя товары по цене, ключевым словам и типу объявлений.

## Возможности

* **Расширяемая архитектура скраперов**: Автоматически переключается на HTML-парсер, если основной скрапер JSON-состояния недоступен. Автоматически поддерживается актуальность и сохранение куки браузера.
* **Современная веб-панель**: Стильный, адаптивный интерфейс на React, Vite и Shadcn UI для управления поисковыми задачами, просмотра истории предложений с фото и быстрой настройки параметров приложения.
* **Защита паролем**: Защита веб-панели паролем из файла `.env`. Пароль хэшируется на стороне клиента с помощью SHA-256 перед отправкой.
* **Интеграция Socket.IO в реальном времени**: Быстрое двунаправленное взаимодействие между веб-панелью и сервером.
* **Telegram Бот**: Помимо веб-панели управление также доступно и прямо в Telegram боте
* **Различные типы уведомлений**:
  * **Telegram Bot**: Интерфейс с инлайн-кнопками для управления задачами и получения уведомлений со прямыми ссылками на объявления.
  * **Discord Webhook**: Поддержка карточек товаров с изображениями и настройкой прокси.
  * **MQTT Broker**: Отправка чистых стандартизированных JSON-структур в системы автоматизации (например, Home Assistant).
* **Управление уведомлениями**: Быстрое включение/выключение провайдеров и настройка параметров (Webhooks, Broker URLs, Chat IDs, прокси) через модальные окна.
* **Продвинутая фильтрация по ключевым словам**: Фильтрация товаров по обязательным (должны быть все) и дополнительным (хотя бы одно) ключевым словам.
* **Поддержка прокси**: Возможность работы через прокси для Telegram, Discord и браузеров Playwright.

## Требования

* Node.js v18+ (для ручной установки)
* Docker и Docker Compose (рекомендуется)

## Конфигурация

Создайте файл `.env` в корневой директории проекта. Все модули независимы и запускаются автоматически при указании соответствующих переменных окружения:

```env
# Настройки веб-сервера
WEB_PORT=3000                                # Запуск веб-панели на порту 3000
WEB_PASSWORD=secret_password                 # Опционально: Пароль для доступа к веб-панели (защищен SHA-256)

# Настройки Telegram бота
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNO # Запуск Telegram бота
TELEGRAM_ADMIN_ID=987654321

# Настройки прокси
PROXY=socks5://user:pass@proxy_host:1080     # Прокси для Telegram и Discord (HTTP/HTTPS/SOCKS5)
AVITO_PROXY=http://user:pass@proxy_host:8080 # Прокси для запросов Playwright к Avito
```

## Веб-панель

Для запуска веб-панели укажите `WEB_PORT` в вашем файле `.env`.
1. Перейдите по адресу `http://localhost:<WEB_PORT>`
2. Если задан `WEB_PASSWORD`, авторизуйтесь с помощью пароля (хэшируется через SHA-256).
3. Управляйте поисковыми задачами, куками и настройками уведомлений с помощью удобных модальных окон и переключателей.
4. Отслеживайте **Статус системы** в реальном времени (`Активен`, `Пауза`, `Выполняется...`), графики аналитики и очищайте историю при необходимости.

## Установка

Клонируйте репозиторий:
```bash
git clone https://github.com/Grovvik/avito-deal-parser.git
cd avito-deal-parser
```

### Ручная установка

1. Установите зависимости бэкенда и бинарники браузеров:
```bash
npm install
npx playwright install chromium --with-deps
```

2. Скомпилируйте React-фронтенд:
```bash
cd frontend
npm install
npm run build
cd ..
```

3. Запустите приложение:
```bash
node index.js
```

## Развертывание

### Docker Compose

1. Создайте директорию `data` для хранения конфигураций и истории:
```bash
mkdir -p data
```

2. Запустите контейнер:
```bash
docker compose up -d --build
```
*(Убедитесь, что `docker-compose.yml` пробрасывает порт `3000:3000`, если используете веб-панель).*

### Docker CLI

```bash
docker build -t avito-deal-parser .

docker run -d \
  --name avito_deal_parser \
  --restart unless-stopped \
  --env-file .env \
  -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  avito-deal-parser
```

## Хранилище данных

Директория `/app/data` содержит:
* `config.json`: Поисковые задачи, интервалы, настройки опроса и динамические параметры уведомлений.
* `deals.json`: История 500 последних отправленных объявлений (используется веб-панелью).
* `cookies.json`: Файл куки браузера, автоматически обновляемый для обхода антибот-систем.
* `sent_ids.json`: Список обработанных объявлений во избежание дубликатов (можно очистить через веб-панель).
